# Historical toolkit rules

These seven files preserve the exact rule bodies retired on 26 November 2026. They are evidence for migration and earlier decisions, not current instructions. Active guidance is in `.claude/rules/*.md`, shared delivery defaults and `docs/CONTEXT_POLICY.md`.

The source manifest in `scripts/retired-rule-hashes.sha256` recognizes unchanged installed LF/CRLF copies. Do not modify these archived originals when updating current policy; their exact contents make lossless migration testable.
