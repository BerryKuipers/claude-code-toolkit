# CoPhusher Project Overlay

This overlay configures the toolkit for the CoPhusher project.

## Prefix

All CoPhusher-specific commands use the `cph-` prefix.

## Configuration

See `config.yml` for project-specific settings.

## Usage

When working in the CoPhusher project:
1. Baseline commands work as normal
2. Toolkit wrappers (`/bk-*`) add verification gates
3. Project commands (`/cph-*`) are CoPhusher-specific
