# Enable Reflection Logging

**Arguments:** (none)

**Description:** Enable the reflection system for the current project. This allows the stop hook to log reflection candidates for later analysis via `/reflect`.

---

## Workflow

### Step 1: Check Current State

```bash
CONFIG_FILE=".claude/config.yml"

# Check if config exists
if [ ! -f "$CONFIG_FILE" ]; then
  echo "Creating .claude/config.yml..."
fi

# Check current state
if grep -q 'reflection:' "$CONFIG_FILE" 2>/dev/null && grep -A1 'reflection:' "$CONFIG_FILE" | grep -q 'enabled: true'; then
  echo "✅ Reflection is already enabled for this project."
  exit 0
fi
```

### Step 2: Update Config File

Read the current `.claude/config.yml` file and ensure it has the reflection section enabled:

```yaml
# Reflection Settings
reflection:
  enabled: true
  # Confidence threshold for logging (LOW, MEDIUM, HIGH)
  confidenceThreshold: MEDIUM
  # Auto-notify on session end
  notifyOnStop: true
```

If the file doesn't have a `reflection:` section, add it at the end.
If the file has `reflection: enabled: false`, change it to `true`.

### Step 3: Initialize State Directory

```bash
mkdir -p .claude/state
mkdir -p .claude/skills/learned
mkdir -p .claude/rules

# Create empty candidates file if not exists
touch .claude/state/reflection-candidates.jsonl

# Create learned patterns files if not exist
if [ ! -f ".claude/rules/19-learned-draft.mdc" ]; then
  cat > .claude/rules/19-learned-draft.mdc << 'EOF'
---
description: Draft learned patterns from reflection (MEDIUM confidence)
globs:
  - '**/*'
alwaysApply: true
---
# Draft Learned Patterns
<!-- Auto-generated by /reflect system -->
<!-- Patterns here are MEDIUM confidence, awaiting promotion -->

## Patterns

(No patterns yet. Run /reflect to analyze sessions.)
EOF
fi

if [ ! -f ".claude/rules/20-learned-patterns.mdc" ]; then
  cat > .claude/rules/20-learned-patterns.mdc << 'EOF'
---
description: Promoted learned patterns from reflection (HIGH confidence)
globs:
  - '**/*'
alwaysApply: true
---
# Promoted Learned Patterns
<!-- Auto-generated by /reflect system -->
<!-- Patterns here are HIGH confidence, verified by user -->

## Patterns

(No patterns yet. Run /promote-learnings to consolidate.)
EOF
fi
```

### Step 4: Print Confirmation

```
✅ Reflection enabled for this project!

What happens now:
  - Stop hook will log reflection candidates
  - Run /reflect to analyze patterns
  - Run /reflect --apply to add patterns to rules
  - Run /promote-learnings to consolidate drafts

Files created/updated:
  - .claude/config.yml (reflection.enabled: true)
  - .claude/state/reflection-candidates.jsonl
  - .claude/rules/19-learned-draft.mdc
  - .claude/rules/20-learned-patterns.mdc

To disable: /reflect-disable
```

## Related Commands

- `/reflect-disable` - Disable reflection logging
- `/reflect` - Analyze and apply learned patterns
- `/promote-learnings` - Consolidate draft patterns
